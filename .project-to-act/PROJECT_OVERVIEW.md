## 基本信息

- 项目名称：AI 产品经理工作台（PM Studio）
- 项目 ID：pm-studio
- 项目负责人：内部产品团队
- 风险等级：高（AI 决策辅助、组织资产与多供应商数据）
- 当前阶段：可运行 MVP / 生产适配
- 当前状态：本机开发版可验收，生产 Gate 未关闭
- 最后更新：2026-08-26

## 项目目标

- 通过持续对话形成可追溯、可审批、可持续演进的产品基线。
- 自动生成结构化提案、分层记忆、Agent 轨迹和交付拆分，同时确保 AI 无权直接修改正式资产。
- 提供可运行的私有云应用骨架，并明确生产存储、队列、对象存储和观测替换点。

## 范围

### 包含

- 单组织账号、RBAC、首次改密、会话与审计基础。
- 项目首页、三栏工作台、移动端、持续对话、提案审批、记忆、来源与管理台。
- OpenAI Agents SDK 经理式编排、DeepSeek 评审适配、Demo 回退和模型能力展示。
- PostgreSQL/pgvector 迁移基线、容器拓扑、Worker 边界和架构文档。

### 非目标

- 多租户、计费、外部任务平台写入、自动开发和自动发布 Agent 版本。
- 在缺少容器和真实供应商凭据时声称生产部署或跨供应商推理已验收。

## 技术路线与关键约束

- pnpm TypeScript monorepo；Next.js App Router Web、独立 Worker、共享 Core 包。
- AI 只生成候选变更；`baseVersion` 冲突必须进入 stale，正式基线版本不可变。
- 开发环境使用原子 JSON；生产必须切换 PostgreSQL repository、持久队列和 S3 对象存储。
- Codex SDK 仅保留为未来只读工程专家，不作为总运行时。

## 数据与安全边界

- 数据分类：内部产品资料，可能包含机密业务信息。
- 敏感信息处理：只记录脱敏摘要、证据 ID 和受控位置，不粘贴原始敏感数据。
- 模型密钥仅由环境变量或 Secret Manager 注入，不进入持久状态、日志或管理台。

## 当前焦点

- 下一里程碑：生产数据层、队列和对象存储实际接线
- 当前工作重点：在具备 Docker/私有云和真实模型凭据的环境关闭生产 Gate
- 主要阻塞：本机无 Docker；未提供 OpenAI/DeepSeek 凭据和目标私有云服务
